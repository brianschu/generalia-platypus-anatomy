# Generalia Platypus museum viewer

Open: https://brianschu.github.io/generalia-platypus-anatomy/platypus-museum-viewer/

Editable project and build instructions: [source](../source/platypus-museum-viewer/README.md).

For Ghost, insert an HTML card in your post or page and paste the contents of [ghost-html-card.html](ghost-html-card.html). Preview the post on desktop and mobile before publishing. The iframe allows fullscreen and includes the anatomy key and pose note.

This single-theme version includes refined skeleton lighting, an immediate preview during rotation, and a wider board that clears from below. It requires a browser with WebGPU enabled.
